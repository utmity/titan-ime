# Titan IME 操作設定（2026-11-05）

## 日本語変換と元のローマ字

通常のローマ字入力では、Mozcによるかな変換と並行して、実際に打鍵した英字を
IME側で保持します。例えば `si` と `shi` は同じ「し」でも、元の入力は区別します。
読み入力中とSpace変換中に `abc: 元の入力` を候補バーに表示します。
この候補のタップは、Mozcの候補IDを介さず現在の未確定範囲全体を元の英字で置き換え、
Mozcのセッションをリセットします。既存の候補ID・順序・学習には手を加えません。

読みの範囲選択・カーソル編集・削除・入力先による書換えなどが起きた後は、
「実際に入力した全文」を保証できなくなるためローマ字候補を消します。
新しい未確定入力を始めると再開します。入力文字列はメモリだけで保持し、
履歴やログに残しません。最大128英字を保持します。

## 物理ショートカットの設定

設定 → 物理キーの各ボタンからキー組み合わせを記録できます。

| 機能 | 初期割り当て |
| --- | --- |
| 日本語・英語の切替 | Fn+Space |
| クリップボード履歴 | Fn+V |
| 選択文字の変換 | Fn+T |

従来の設定（Sym/Alt+Space、Fn+B、Fn+Gなど）も、新しいキー割り当てを
明示的に保存するまでは読み継ぎます。履歴と文字変換は無効化できます。
修飾キーなし、Shiftだけ、同じ機能間での重複割り当て、
Fn+H/L/J/K/U/O/A/D/W/S/Backspace（編集・文節操作で使用）は受け付けません。
登録できてもシステムや入力先アプリに先取りされる組み合わせは有効になりません。

キー設定はSharedPreferencesへ保存し、IME稼働中はキーコード＋修飾マスクを
メモリ上のプロファイルで比較します。設定変更の通知でプロファイルを更新し、
通常のキー入力ごとに設定ファイルを読むことはありません。

## 候補バーの表示

設定 → 入力・変換 → 候補バーの表示から以下を選択できます。

- **通常時も表示**（初期値）：従来動作
- **日本語入力・変換中のみ表示**：未確定文字列があるときに表示
- **変換中のみ表示**：Space変換中に表示し、読み入力中はバーを折りたたむ

メニュー、音声入力、Androidのインライン自動入力が稼働中の場合は表示を優先します。
読み入力中はIMEを閉じて未確定文字を意図せず確定しないよう、
ツールバー本体と補助余白をGONEにして高さを縮めます。
未確定文字がなく表示が不要な場合はIMEウィンドウを閉じます。
設定はIMEの専用候補バーを対象とし、Androidのナビゲーションバーを改造しません。

## ユーザー向けガイドと設定文言

設定内の「操作ガイド」は現在のショートカット割り当てを読み、
入力、文字変換、候補、音声、履歴、IME切替、プライバシー、制限を説明します。
開発経緯の「廃止しました」等は設定画面から除外しています。

## 確認すべき実機項目

- `nihongo` → 日本語候補と `abc: nihongo`、`shi` / `si` の差
- 変換確定後、Backspace・カーソル修正後、パスワード欄で誤った元入力が残らない
- Ctrl+Space・Fn+Space等の割り当て変更、競合拒否、設定即時反映
- 非表示設定とSpace変換中の再表示、音声・IME切替・インライン自動入力の動作
- Niagara、ChatGPT、Discord、Termuxの入力欄で未確定文字が失われない

CIのビルド・JVMテストは行えますが、TITAN 2 ELITEの実機挙動は別途確認が必要です。
